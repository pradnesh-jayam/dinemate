# 🍽️ DineMate

> **Discover Restaurants. Meet People. Dine Together.**

[![Live Demo](https://img.shields.io/badge/Live-Demo-success)](https://dinemate07.netlify.app/)
![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue)
![Firebase](https://img.shields.io/badge/Firebase-Firestore-orange)
![Vite](https://img.shields.io/badge/Vite-Frontend-purple)

A modern social dining platform that helps people discover restaurants, create dining events, connect with nearby food enthusiasts, and chat in real time.

Built with a scalable modular architecture using **TypeScript**, **Firebase**, and **Firestore** with real-time synchronization.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/pradnesh-jayam/dinemate.git
```

Install dependencies

```bash
npm install
```

Create `.env.local`

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
```

Run locally

```bash
npm run dev
```

# 💡 Why DineMate?

Finding people to dine with can be difficult, especially in a new city or college campus.

DineMate makes social dining simple by allowing users to create dining events, discover nearby restaurants, connect with like-minded people, and communicate in real time through a modern web platform.
